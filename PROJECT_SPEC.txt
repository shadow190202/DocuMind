============================================================

1. PROJECT OVERVIEW
   ============================================================

PURPOSE:

Build an AI-powered document intelligence platform that allows
users to upload documents, search their documents, ask questions
about document content, generate summaries, and compare documents.

The system should provide answers based on the user's uploaded
documents and show the relevant document/source information
whenever possible.

============================================================
2. PROBLEM STATEMENT
====================

Users often have large PDF, DOCX, TXT and CSV files that are
difficult to search manually.

The system should allow users to upload their documents and
interact with the information using natural-language questions.

The application should retrieve relevant document content before
generating an AI response.

============================================================
3. TARGET USERS
===============

1. Normal User
2. Administrator

============================================================
4. MAIN OBJECTIVES
==================

1. Allow users to securely upload documents.
2. Extract text from supported documents.
3. Process documents into searchable chunks.
4. Generate embeddings for document content.
5. Store searchable document information.
6. Allow users to ask questions about their documents.
7. Retrieve relevant document content.
8. Generate answers using an AI model.
9. Show source/document information with answers.
10. Maintain conversation history.
11. Provide document summarization.
12. Support document comparison.
13. Provide user-level document permissions.
14. Provide an administrator dashboard.
15. Deploy the application.

3. Store file.
4. Extract text.

6. Generate embeddings.

User flow:

↓
System identifies relevant documents
↓
Vector search
↓
Retrieve relevant chunks
↓
Send relevant context to AI model
↓
Generate answer
↓
Display answer + source information
